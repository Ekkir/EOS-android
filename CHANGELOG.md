# CHANGELOG — EOS

## [1.2.14] — 2026-08-24

### Новые функции
- **Статусы доступа для пользователей** — администратор может выбрать один из трёх статусов: «Подтверждён», «Приостановлен», «Отказано»
- **Приостановка доступа** — новый статус `suspended`: пользователь видит экран «Доступ приостановлен» с кнопкой «Ожидать», может ждать восстановления или выйти
- **Экран ожидания адаптируется** к статусу: иконка и цвет меняются при смене `pending` → `suspended`

### Улучшения
- **Список пользователей у администратора** — добавлена секция «Приостановленные» (оранжевая); для одобренных пользователей появилась кнопка «Приостановить»; кнопки теперь `Wrap` — не обрезаются на узких экранах
- **Эндпоинт сервера** `POST /admin/suspend` — переводит пользователя в статус `suspended`

## [1.2.13] — 2026-08-23

### Новые функции
- **Терминальная анимация при Google-входе** — тёмно-синий градиент, хедер EOS, авторизация (email + ••• пароль), системные проверки, «Нарушение безопасности», подключение к серверу, ожидание ключа от администратора
- **Экран остаётся до подтверждения** — опрашивает сервер каждые 10 секунд, навигация только после `approved`/`rejected`
- **Логирование проверки обновлений** — при ручной проверке в разделе «О приложении»: полный лог шагов, при ошибке — диалог с кнопкой «Отправить лог» (авто-заполнение, сохраняется в bug_reports на сервере)
- **Автоматическая очистка кэша установщика** — при каждом запуске все `eos_update_*.apk` удаляются

### Улучшения
- Авто-проверка обновлений на HomeScreen остаётся тихой (без диалогов ошибок)
- Ручная проверка в AboutScreen получила логирование и диалог ошибки с отправкой лога

### Сервер (ekkir@192.168.0.15)
- `POST /admin/suspend` — устанавливает статус `suspended` для пользователя

## [1.1.32] — 2026-07-30

### Новые функции
- **Статус онлайн** — зелёный индикатор в профиле пользователя (активен < 3 мин)
- **Синхронизация анимации аватара** — другие видят выбранный эффект (aurora/glitch/disintegration) в чате и при открытии профиля
- **Описание профиля (bio)** — поле «О себе» с подписью «информацию о себе будут видеть другие»; отображается в профиле других пользователей
- **Отключение уведомлений по чатам** — кнопка mute/unmute в заголовке каждого чата; работает и в фоновом режиме (FCM background)
- **Удаление сообщений у всех** — при удалении своего сообщения оно исчезает у всех участников при следующем обновлении

### Улучшения
- **Плашка обновления** открывается выше середины экрана (`initialChildSize: 0.58`)
- **Настройки анимаций аватара** — слайдеры интенсивности и скорости для глитча, авроры, дезинтеграции
- **Аватар в боковом меню** — обновляется сразу после изменения в профиле
- **Анимация EOS** в разделе «О приложении» — устранена прерывистость (плавный маятниковый шиммер)
- **Профиль другого пользователя** — убрано отображение email

### Удалено
- Эффект аватара «Визуализатор»

### Сервер (ekkir@192.168.0.15)
- `POST /ping` — обновляет время последней активности
- `GET /profile/<email>` — добавлено поле `is_online`, `bio`, `avatar_effect`, `google_email`
- `POST /profile` — сохраняет `bio` и `avatar_effect`
- `GET /messages` — возвращает `{messages, deleted}` вместо плоского списка
- `DELETE /messages/<id>` — добавляет id в `_deleted_ids[channel]` (хранит до 200 последних)
